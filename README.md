PR Tracker

A modern React-based Pull Request Tracking Dashboard that helps development teams monitor, review, and manage pull requests efficiently. The application provides filtering, searching, repository-based organization, PR status tracking, and merge simulation in a clean and intuitive interface.

Features

* View all pull requests in a centralized dashboard
* Track PR statuses:
    * Open
    * In Review
    * Merged
    * Closed
* Filter pull requests by repository
* Search PRs by:
    * Title
    * Author
    * PR Number
* Display CI/CD check status indicators
* View comment counts and branch information
* Simulate PR merging for review-ready pull requests
* Responsive and clean UI built with Tailwind CSS

Tech Stack

* React.js
* JavaScript (ES6+)
* Tailwind CSS
* React Hooks
    * useState
    * useMemo

Dashboard Overview

Pull Request Information

Each PR card displays:

* PR title
* PR number
* Author
* Repository
* Source and target branches
* Status badge
* Comments count
* CI/CD checks status
* Age of pull request

Statistics Panel

The dashboard provides quick insights into:

* Open PRs
* PRs under review
* Merged PRs
* Closed PRs

Repository Filters

Filter pull requests by:

* All Repositories

* Infrastructure
